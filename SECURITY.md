# Security policy

This repository holds the generated pages of https://contasdabola.pt/. It is written only by an automated
publish job; nobody edits it by hand.

## Reporting a vulnerability

Please report it privately, through GitHub's "Report a vulnerability" button on the Security
tab of this repository, or by email to contasdabola@gmail.com. Do not open a public issue.

Useful details: the address of the page, what you saw and how to reproduce it. You will get a
reply within 7 days.
